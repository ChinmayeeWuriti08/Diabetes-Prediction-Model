#  Diabetes Prediction — Machine Learning

An end-to-end machine learning project that analyzes healthcare data and predicts diabetes outcomes using a **WHO diabetes dataset**.

## Project Overview

* Performed **Exploratory Data Analysis (EDA)** to identify patterns, distributions, correlations, and potential data-quality issues.
* Applied multiple **data cleaning and preprocessing techniques** to prepare the dataset for modeling.
* Used **Matplotlib** for data visualization and analysis.
* Split the dataset into **80% training and 20% testing** data.
* Applied **feature scaling with StandardScaler** while avoiding data leakage.
* Trained a **classification model** to predict diabetes outcomes.
* Achieved **93% accuracy** on the test dataset.

##  Tech Stack

**Python · Pandas · NumPy · Matplotlib · Scikit-learn · Jupyter Notebook**

## Results
**Test Accuracy: 93%**

The model successfully learned patterns from the processed healthcare data and produced strong classification performance on unseen test data.
